## 独立项目仓库

完整可展示的项目单独建仓库（简历作品），当前规划：

- `expense-tracker`：个人记账系统（项目1）
- `ai-knowledge-base`：旗舰项目 · AI 知识库问答

## 每日提交规范

1. 学习完一个节点 → 把笔记写进 `docs/对应阶段/`
2. 练习代码放进 `exercises/对应主题/`（文件名带节点编号，如 `node15_func.py`）
3. 提交：`git add .` → `git commit -m "feat: 节点15-函数"` → `git push`
